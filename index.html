About This System

Features:

  • ✅ Face Recognition using AI
  • ✅ Fingerprint Biometric Scanning
  • ✅ Real-time Attendance Marking
  • ✅ Student Registration Management
  • ✅ Attendance Reports & Analytics
  • ✅ Export to Excel

How to Use:

  1. Register: First, register students with their photo
  2. Attend: Students can mark attendance using face or fingerprint
  3. View: Admin can view all attendance records
  4. Report: Generate and download reports

Technologies Used:

Frontend: HTML, CSS, JavaScript
Backend: Python, Flask
Face Recognition: OpenCV, face_recognition library
Database: SQLite
